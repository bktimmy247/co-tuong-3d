# Cờ Tướng 3D — Royal Xiangqi

Game Cờ Tướng 3D chạy trực tiếp trên trình duyệt.

## Hiện có

- Three.js + WebGL, không cần backend.
- Bàn Cờ Tướng 9×10 với sông và cung.
- Đủ 32 quân: Tướng/Sĩ/Tượng/Xe/Pháo/Mã/Tốt.
- Luật đi quân, cản chân Mã, cản mắt Tượng, Pháo qua ngòi, Tướng đối mặt.
- Lọc nước đi để không tự đưa Tướng vào thế bị chiếu.
- Chiếu tướng, chiếu bí / hết nước.
- Hai người trên cùng thiết bị.
- Đấu máy: Dễ / Vừa / Khó.
- Hoàn tác, ván mới, lật camera.
- Nhạc nền + SFX tạo cục bộ.
- Giao diện mobile-first cho iPhone/iPad.

## Chạy

Mở `index.html` qua một static server hoặc GitHub Pages.
